# trace_analyzer

https://sovenov.github.io/trace_analyzer/

Локальный разбор выгрузок Kibana по трейсам AlfaGen / AIAD_CHAT. Всё считается в браузере, логи никуда не отправляются.

## Структура

```
index.html            разметка страницы, подключает css и js
css/styles.css        все стили
js/parser.js          разбор записей → трейсы, хроника, статистика, бюджет MCP (без DOM)
js/contracts.js       контракты между сервисами (без DOM)
js/app.js             состояние, загрузка файлов, сохранение отчёта, экспорт
js/budget.js          блок «бюджет токенов MCP»
js/report.js          вкладки трейсов и отчёт
js/contracts-ui.js    блок «Контракты»
js/raw.js             блок «Сырые записи»
```

Скрипты подключаются в этом порядке; `parser.js` и `contracts.js` можно склеить и запускать в node.

## Кэш

У ссылок на css/js в `index.html` стоит `?v=N`. После изменения любого css/js увеличьте N, иначе браузер или GitHub Pages могут отдать старую версию.

## «Сохранить отчёт»

Отчёт — один html-файл со вложенными логами. Стили и скрипты он подключает с GitHub Pages (`https://sovenov.github.io/trace_analyzer/css/…`, `…/js/…`), откуда бы ни был открыт анализатор. Поэтому отчёт открывается на любом компьютере с интернетом, но без интернета не работает, и показывает логи текущей версией анализатора на GitHub Pages — после пуша изменений в css/js они сразу видны и в старых отчётах.
